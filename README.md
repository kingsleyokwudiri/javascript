# My JavaScript Learning Journey 🟨 🚀

Welcome to my repository! This is a personal archive of the projects and exercises I built while learning JavaScript, from basic language concepts to interactive browser apps.

## 📂 Project Structure

- `/Basics` - Core JavaScript fundamentals like variables, operators, conditionals, arrays, and loops.
- `/Functions_and_Objects` - Reusable functions, scope, object literals, and data modeling.
- `/DOM_Manipulation` - Examples that manipulate HTML/CSS in the browser and respond to user interaction.
- `/Mini_Projects` - Small interactive applications with practical UI and state management.

## 🌟 Featured Projects

- **Amazon Clone** (`Mini_Projects/amazon`)
  - A browser-based storefront with product data, cart interaction, and checkout flow.
  - _What I learned:_ structuring a multi-page app, modular JavaScript, and working with JSON data.
- **Calculator** (`Mini_Projects/calculator`)
  - A functional calculator with buttons for digits, operators, and clear actions.
  - _What I learned:_ managing application state, parsing user input, and updating the display.
- **Clock** (`Mini_Projects/clock`)
  - A live digital clock interface built with JavaScript timing functions.
  - _What I learned:_ using `setInterval` and dynamic DOM updates.
- **Coin Flip Game** (`Mini_Projects/coin_flip`)
  - A randomized game of heads or tails against the computer.
  - _What I learned:_ generating random values and handling game results.
- **Rock, Paper, Scissors** (`Mini_Projects/rockpaperscissors`)
  - An interactive version of the classic hand game with score tracking.
  - _What I learned:_ conditional game logic and updating the UI from JavaScript.
- **To-Do List App** (`Mini_Projects/to-do-list`)
  - A productivity app for adding, completing, and deleting tasks.
  - _What I learned:_ DOM manipulation, event handling, and browser Local Storage persistence.

## 🧠 Key Skills Practiced

- **JavaScript fundamentals:** variables, loops, arrays, functions, and objects.
- **DOM manipulation:** selecting elements, changing content, adding/removing elements, and handling events.
- **Browser APIs:** using Local Storage, timers, and user input.
- **Responsive app behavior:** updating UI state based on user actions.

## 🚀 How to Use

1. Open the project folder in your browser or VS Code.
2. Open any HTML file from the directories above.
3. View the project live by opening the file directly in your browser.
