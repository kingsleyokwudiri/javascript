# My JavaScript Learning Journey 🟨 🚀

Welcome to my repository! This personal archive contains the projects and exercises I built while learning JavaScript, from basic language concepts to interactive browser applications.

## 📂 Project Structure

- `Basics` — Core JavaScript fundamentals, including variables, operators, conditionals, arrays, and loops.
- `Functions_and_Objects` — Reusable functions, scope, object literals, and working with structured data.
- `DOM_Manipulation` — Browser-based examples that manipulate HTML/CSS and respond to user interaction.
- `Mini_Projects` — Small interactive applications with real UI behavior and state management.

## 🌟 Featured Projects

- **Amazon Clone** (`Mini_Projects/amazon`)
  - A browser storefront with product cards, cart interaction, checkout flow, and JSON-backed product data.
  - _What I learned:_ multi-page app structure, modular JavaScript, and loading data from JSON.
- **Calculator** (`Mini_Projects/calculator`)
  - A working calculator with digit buttons, operations, decimal handling, and clear functionality.
  - _What I learned:_ managing input state, implementing arithmetic operations, and updating the display.
- **Clock** (`Mini_Projects/clock`)
  - A live digital clock that updates every second.
  - _What I learned:_ using `setInterval` and dynamically updating the DOM.
- **Coin Flip Game** (`Mini_Projects/coin_flip`)
  - A simple game that simulates a coin toss and displays win/loss results.
  - _What I learned:_ generating random outcomes and showing results with JavaScript.
- **Password Generator** (`Mini_Projects/password_generator`)
  - A tool for generating secure passwords with customizable length and character options.
  - _What I learned:_ working with strings, random selection, and user input validation.
- **Rock, Paper, Scissors** (`Mini_Projects/rockpaperscissors`)
  - An interactive hand game with score tracking and result updates.
  - _What I learned:_ game logic, event handling, and UI updates.
- **To-Do List App** (`Mini_Projects/to-do-list`)
  - A task manager for adding, completing, and removing items.
  - _What I learned:_ DOM manipulation, browser events, and Local Storage persistence.

## 🧠 Key Skills Practiced

- JavaScript fundamentals: variables, loops, arrays, functions, and objects
- DOM manipulation: querying elements, modifying content, and creating/removing nodes
- Browser APIs: Local Storage, timers, and user input handling
- UI state management: updating the page in response to user actions

## 🚀 Getting Started

1. Open this repository in VS Code.
2. Choose a project folder and open the HTML file for that project.
3. Open the page in your browser directly or use a local server extension such as Live Server.

> Tip: For projects that load JSON or use advanced browser behavior, running a local server provides the best experience.
